#e5e7eb\n--border-dark: #d1d5db\n```\n\n## Tips & Best Practices\n\n1. **Always use `.card` for content sections** - Ensures consistent styling\n2. **Use `.table-responsive` for tables** - Makes them mobile-friendly\n3. **Add meaningful subtitles** - Helps users understand context\n4. **Color code status badges** - Green for good, red for bad\n5. **Use consistent spacing** - Use the spacing scale (xs, sm, md, lg, xl, 2xl)\n6. **Test on mobile** - Use browser DevTools device emulation\n7. **Keep forms vertical on mobile** - Use 2-column grid only on desktop\n8. **Add empty state messaging** - Helps users understand when data is missing\n9. **Use action buttons consistently** - Edit, Delete, View actions\n10. **Follow the grid structure** - Maintains visual hierarchy\n\n---\n\n**Last
